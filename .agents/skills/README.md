# Curated community skills

These repo-scoped skills were added because they are both useful here and already battle-tested in the public skills ecosystem. Selection rule: prefer skills with strong adoption on `skills.sh`, clear overlap with this repo's actual workflows, and passing security audits when that data is available.

| `verification-before-completion` | `obra/superpowers` | Forces fresh evidence before claiming a fix shipped or a test passed. | 110.1K installs on `skills.sh`; 3/3 scanners passed |
| `playwright-best-practices` | `currents-dev/playwright-best-practices-skill` | Deep Playwright reference for browser QA, flake reduction, auth flows, accessibility, and CI. | 51.0K installs on `skills.sh`; 3/3 scanners passed |

This is intentionally curated, not a landfill. A skill being popular is not enough; it also needs to earn its keep in this repo.
